# Shipped recipes

Recipes the package ships, one `<id>.recipe.json` per recipe revision, validated by the `Recipe` schema in `src/services/architect/schemas.ts`. The catalog loads every `*.recipe.json` here and reports invalid files with their reason ([ARCH](../../dev/ARCH.md#decision-log), TODO 2.4).

Each output declares what one run writes for its role (`format`, `count`), so the contract layer can tell a task asking for another format or more images apart from one the recipe serves; a task field that no slot fills and no declaration covers stays a hard unknown. A model slot's `default` names the file the recipe was written for; a different file in the slot makes the candidate diagnostic until file families can be verified (GAPS Q14). A change to a recipe bumps its `revision`: the catalog refuses a changed file under a revision it already holds.

The first three cover Z-Image Turbo (text to image, image to image) and FLUX.1-schnell (text to image from separate components), the families of GAPS Q12. An agent wrote them; the owner reviewed them, so they're `curated` (spec §8.4). `recipe-flux1-schnell.ckpt-t2i` loads FLUX.1-schnell from Comfy-Org's all-in-one checkpoint with `CheckpointLoaderSimple`, as ComfyUI's `flux_schnell` template does; the file has to be in `checkpoints/` (GAPS Q13). It's `proposed` until reviewed.

A recipe pins the source of each model file it can acquire in `modelSources`: folder, file name on disk, and a Hugging Face repository at a 40-character commit with the path, sha256 and size Hugging Face reports, written with `node scripts/architect/pin-source.mjs <repo> <path> [revision] --folder <folder> [--file <name>]` and never by hand. Planning reads them offline: a candidate whose only failing checks are model files with a pinned `.safetensors` source within the size limit is `acquirable` (ARCH 2026-11-16; GAPS Q25). The Z-Image recipes pin their three files from `Comfy-Org/Z-Image-Turbo` (requested as `Comfy-Org/z_image_turbo`, which Hugging Face redirects). `recipe-zimage-turbo.t2i-upscale2x` generates at half the task's width and height (`fromTaskDivisor` 2), upscales 4x with RealESRGAN x4plus from `Comfy-Org/Real-ESRGAN` and scales by 0.5, so the image has the task's size; it's `proposed` until reviewed. Test fixtures, certification `fixture`, live in `src/__tests__/architect/fixtures/` and are never placed here.
